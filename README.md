# 清流 Qingliu

一个开源的“短视频用户控制层”原型：把内容从被动刷取，变成可核验、可比较、可整理、可控制、可行动的信息。

## 解决的问题

- 内容核验：显式检查来源、时效、利益关系和强断言。
- 消费决策：比较到手价、退货成本与证据完整度，并设置冷静期。
- 收藏行动化：把收藏内容合并为可执行任务。
- 推荐控制：用主题配额、内容边界和临时模式表达偏好。
- 本地决策：补齐排队、停车、老人儿童友好等信息。
- 安全与长辈模式：过滤攻击性评论，提供清晰的购物与维权路径。
- 本地优先：用户数据默认保存在浏览器，可自行导出。

## 市场位置

现有产品多解决局部问题：抖音提供内容分发、辟谣卡和电商治理；小红书偏生活经验搜索；Readwise Reader 擅长保存、转录与知识整理；Inoreader 擅长订阅、过滤和去重。清流探索的是把“核验 → 决策 → 行动 → 偏好 → 安全”串成统一工作流。

详细比较与产品取舍见 [竞品学习地图](COMPETITORS.md)。

## 运行

无需构建步骤：

```bash
python3 -m http.server 4173 --directory dist
```

打开 `http://localhost:4173`。也可以直接打开 `dist/index.html`。

## 当前边界

这是可交互 MVP，不会绕过平台权限抓取抖音数据，也不把启发式评分包装成事实核查。真实产品需要得到平台接口授权，并接入可信来源、价格历史、地点实时数据和专业审核体系。

## 隐私

所有演示数据默认仅写入浏览器 `localStorage`。项目不包含跟踪器、广告 SDK 或后端账户系统。
